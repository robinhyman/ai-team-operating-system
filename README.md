# AI Team Operating System

Reusable operating artefacts for an AI software delivery team.

Start by adapting:

- `project-state/status.md`
- `project-state/handoff.md`
- GitHub repository and Project references
- the active project profile

Core principle:

> The chat is temporary. The repository is memory. GitHub tracks work.

Use this repository as a baseline for projects that will be delivered by a Lead agent coordinating specialized worker agents through GitHub issues, increments, verification, documentation, and retrospectives.
